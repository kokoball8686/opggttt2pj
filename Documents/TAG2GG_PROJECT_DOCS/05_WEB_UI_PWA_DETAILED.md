# 05. 웹 UI·반응형·PWA 상세 문서

## 1. 디자인 방향

TAG2.GG는 어두운 e스포츠 통계 사이트 분위기를 목표로 했다.

- 배경: 짙은 네이비/슬레이트
- 포인트: 네온 블루와 레드
- 카드: 어두운 그라데이션과 얇은 테두리
- 글꼴: Pretendard 계열
- 정보 밀도: 데스크톱은 넓게, 모바일은 압축

## 2. 데스크톱 배치

`main.css`는 상단 고정 바와 좌측 고정 사이드바를 사용한다. 대시보드는 통계 카드, 캐릭터 픽률, 태그 조합, 급상승 플레이어, 활동 차트, 최근 경기를 배치한다.

## 3. 반응형 기준

### 900px 이하

대시보드를 블록 흐름으로 바꾸고, 패널을 1열로 쌓는다. 통계 카드는 2열이다.

### 640px 이하

상단 햄버거 메뉴, 슬라이드 사이드바, 작은 패널 여백, 2행형 막대그래프, 모바일 경기 그리드를 사용한다.

### 360px 이하

프로필 지표·태그 이미지·승률 차트를 추가 축소한다.

## 4. 모바일에서 해결한 문제

- 통계 카드가 한 줄에 들어가지 않던 문제
- 캐릭터 픽률 이미지와 퍼센트가 겹치던 문제
- 최근 경기의 점수와 이미지가 겹치던 문제
- 플레이어 닉네임이 공간 부족으로 사라지던 문제
- 프로필 원형 승률 차트가 너무 크던 문제
- `27전 12승 15패` 같은 기록이 줄바꿈되던 문제
- 패널 사이 간격이 일정하지 않던 문제

## 5. PWA 매니페스트

`manifest.json`은 `display: standalone`, 시작 경로 `index.html#home`, 192px/512px 아이콘, 어두운 테마를 정의한다. Android Chrome에서 홈 화면에 추가하면 브라우저 탭보다 앱에 가까운 형태로 실행된다.

## 6. 서비스 워커

`sw.js`는 앱 셸을 `tag2-gg-shell-v2`에 캐시한다.

```javascript
self.addEventListener('fetch', event => {
  if (event.request.method !== 'GET') return;
  event.respondWith(
    fetch(event.request).catch(() => caches.match(event.request))
  );
});
```

정적 화면은 네트워크 실패 시 캐시에서 열 수 있지만, Supabase 경기 데이터까지 완전 오프라인으로 보장하는 구조는 아니다.

## 7. 설치 안내서

`Documents/TAG2GG_PWA_설치_가이드.html`과 PDF는 Android Chrome에서 링크를 열고 홈 화면에 추가하는 과정을 6장의 이미지로 설명한다. 제조사와 Android 버전에 따라 메뉴명이 달라질 수 있다는 주의사항도 포함한다.
