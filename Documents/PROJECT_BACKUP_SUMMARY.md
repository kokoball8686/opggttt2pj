### 1. 프로젝트 핵심 목표 및 방향성

* **목적**: RPCS3 에뮬레이터 사설 서버(RPCN) 환경에서 진행되는 철권 태그 2 온라인/오프라인 대전 기록을 자동으로 감지하고, 이를 중앙 통합 DB로 수집하여 OP.GG 스타일의 전적 웹사이트(`TAG2.GG`)에 실시간으로 시각화함.
* **배포 전략**:
  * **클라이언트 프로그램**: 단톡방/커뮤니티 사용자들이 별도의 로그인, 회원가입, 닉네임 입력 없이 다운받아서 더블클릭만 하면 무인(Zero-config)으로 동작하는 단일 실행 파일(`TTT2_Tracker.exe`) 형태로 배포 (PyInstaller 활용).
  * **웹 및 백엔드**: 100% 무료 서버리스 인프라 (Supabase PostgreSQL DB + Netlify 글로벌 호스팅) 기반으로 구축하여 유지비 0원 달성.

### 2. 메모리 파싱 기술 성과 (100% 검증 완료 목록)

RPCS3의 64비트 가상 메모리 공간(`0x300000000` 대역) 및 PS3 Cell Big-Endian 구조를 해석하여, 에뮬레이터 재시작 및 컴퓨터 재부팅 후에도 100% 신뢰할 수 있는 메모리 오프셋 공식을 완벽히 정복함.

| 항목 | 메모리 주소 / 공식 | 데이터 형태 | 비고 / 검증 상태 |
| :--- | :--- | :--- | :--- |
| **RPCS3 PS3 RAM Base** | `동적 탐색` (기준값 `0x300000000`) | Process RAM | `VirtualQueryEx`로 PC별 실제 게스트 RAM 매핑 확인 |
| **1P 닉네임** | `RAM base + 0x167D118` | String (32 bytes) | 게스트 RAM 기준 상대 오프셋 |
| **2P 닉네임** | `RAM base + 0x167F3B8` | String (32 bytes) | 게스트 RAM 기준 상대 오프셋 |
| **메인 포인터** | `RAM base + 0x100D2ABC` | 4-byte Big-Endian Ptr | 전투 구조체(`BattleStruct`) 가리키는 상대 위치 |
| **1P 라운드 승수** | `[RAM base + 0x100D2ABC] + 0xB` | Byte (0, 1, 2, 3) | 3승 도달 시 대전 종료 판정 |
| **2P 라운드 승수** | `[RAM base + 0x100D2ABC] + 0xB + 0xD4` | Byte (0, 1, 2, 3) | 1P 주소와 `0xD4` (212바이트) 고정 오프셋 차이 |

### 3. 클라이언트 트래커 엔진 (`tracker.py`)

* **위치**: `C:\1\ttt2_tracker\tracker.py`
* **기술 스택**: Python 3.x, `ctypes` (Win32 API `ReadProcessMemory`), `urllib.request` (내장 HTTP 통신)
* **작동 로직 (상태 머신)**:
  1. `rpcs3.exe` 프로세스를 2초 주기로 자동 탐지하여 `OpenProcess` 핸들 획득.
  2. `VirtualQueryEx`로 해당 PC의 RPCS3 게스트 RAM 매핑 base를 동적으로 찾고, 검증된 상대 오프셋을 적용.
  3. 0.3초 주기로 메모리 뷰어링.
  4. `1P 승수 == 0` AND `2P 승수 == 0` 감지 시 ➔ `🥊 [NEW MATCH DETECTED]` (시작 시각 기록).
  5. `1P 승수 == 3` OR `2P 승수 == 3` 감지 시 ➔ `🏆 [MATCH RESULT LOGGED]` (종료 시각 기록 및 중복 전송 방지 깃발 세움).
  6. 대전 결과를 JSON으로 포맷팅하여 Supabase REST API로 자동 POST 업로드.

### 4. 백엔드 클라우드 DB (Supabase PostgreSQL)

* **Supabase 프로젝트 URL**: `https://hnmwidamrbcslnaykaem.supabase.co`
* **테이블 스키마 (`public.matches`)**:
  ```sql
  create table public.matches (
    id bigint generated by default as identity primary key,
    p1_name text not null,
    p2_name text not null,
    p1_score smallint not null,
    p2_score smallint not null,
    winner text,
    start_time timestamp with time zone,
    end_time timestamp with time zone,
    created_at timestamp with time zone default now()
  );
  ```
* **보안 및 디두플리케이션 정책**:
  * 개발 편의를 위해 `RLS (Row Level Security)` 비활성화.
  * 복수 유저가 동시 접속하여 같은 대전을 치렀을 때 **30초 시간 창(Time-Window) 디두플리케이션 알고리즘**을 통해 동일 대전 기록 자동 합치기(Merge) 설계 적용.
